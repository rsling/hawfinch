# data

Nothing in this directory is tracked by git except this file, placeholders, and release manifests.

- `raw/`: German Wiktionary dumps, one subdirectory per dump date.
- `interim/`: parsed but not yet normalised intermediates. Safe to delete; regenerated by the extractor.
- `release/`: versioned outputs of the extractor, one subdirectory per version (e.g. `v0.1.0/`). Each holds the Parquet tables, a DuckDB file, and a `MANIFEST.json` recording the dump date, the extractor commit, and checksums. Only the manifest is tracked.

Releases are the only interface between the extractor and the rest of the project. The schema of a release is documented in `docs/schema/`.
